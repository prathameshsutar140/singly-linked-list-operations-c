# Menu-Driven Singly Linked List in C

This repository contains a C program that implements an interactive, menu-driven Singly Linked List capable of performing core data structure operations dynamically at runtime[cite: 9].

---

## Key Operations Supported

* **List Initialization**: Dynamically builds the initial linked list using `malloc()`[cite: 9].
* **Insert at Beginning**: Adds a new node to the front of the list (`head`)[cite: 9].
* **Insert at Specific Position**: Inserts a node at a user-defined position index[cite: 9].
* **Insert at End**: Appends a new node to the end of the list[cite: 9].
* **Delete Element**: Searches for a targeted value and frees its memory allocation[cite: 9].
* **Display List**: Traverses from `head` to `NULL` to print all stored values[cite: 9].

---

## Technical Information

* **Language:** C[cite: 9]
* **Header Files:** `<stdio.h>`, `<conio.h>`, `<stdlib.h>`[cite: 9]
* **Memory Management:** Dynamic memory allocation using `malloc()` and `free()`[cite: 9]
* **Environment:** Compatible with **Turbo C / Turbo C++** or standard C compilers[cite: 9]
